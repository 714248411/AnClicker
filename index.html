01 · What · 功能定位

把重复操作，变成可复用的流程。

AnClicker 将键鼠操作、图像识别、OCR、Excel 和网页操作，组织成可保存、可重复执行的流程。你决定每一步如何运行，也决定何时接入模型与外部服务。

Local first

本地执行 · 数据由你掌控

指令、配置、日志与截图保存在本机，可按数据目录备份与迁移。

Visual workflow

可视化编排 · 每一步都清晰

表格与流程图双编辑，用顺序、循环和条件判断表达实际任务。

02 · Pipeline · 流程搭建

从操作到流程，只需五步。

先搭建，再检查。让每次触发，都有清晰的执行路径。

01

添加指令

从指令树拖入节点，或录制实际的键鼠操作。

02

配置参数

设置目标、变量、时间间隔与识别条件。

03

连接流程

用连线组织顺序、判断、循环与后续步骤。

04

运行观察

开始、暂停、恢复，通过日志观察执行情况。

05

保存复用

保存流程，按需导出、备份与迁移任务数据。

03 · Capabilities · 核心能力

从一次点击，到一整套工作流。

按需组合能力，让重复任务有章可循。

01 / Input

系统级键鼠模拟操作

点击、双击、拖拽、滚轮与组合键；支持配置间隔与延时。

02 / Record

键鼠录制与回放

记录操作，再将录制结果继续编辑并加入流程。

03 / Vision

图像识别与 OCR

结合坐标、图像、文字识别完成定位与后续操作。

04 / Data

变量与 Excel

管理全局及任务变量，导入导出流程，复用任务数据。

05 / Window

窗口绑定与后台操作

Windows 可按组件和绑定模式配置后台键鼠、截图与取色。

06 / Extend

独立指令 · 开放扩展

通过独立参数编辑器、执行器与统一注册表维护扩展。

04 · Workspace · 界面展示

每一步，都有清晰的工作界面。

表格精确编辑，流程图梳理逻辑，录制还原操作，对话辅助起草。四个工作页，连接同一套自动化流程。

逐条编辑，运行有据可查。

在指令表格中查看参数与重复设置，通过运行日志观察任务进展。

把执行逻辑，连接成图。

用节点与连线组织顺序、循环和分支，直观看清任务的执行路径。

操作一次，成为可编辑的步骤。

设置倒计时与录制选项，预览键鼠事件，再写入表格与流程图。

从一句需求，到指令草稿。

对话生成的指令先保存在草稿区，可检查参数、调整顺序，再写入工作流。

05 · Agent · 对话 Agent

用对话起草，让流程落地。

v1.6.3 提供对话 Agent。可配置本地小模型或兼容模型服务，辅助编写指令草稿、修改参数及操作独立浏览器。

Draft

先生成草稿

把自然语言需求拆成可编辑的指令步骤，保留人工检查与调整入口。

Execute

检查后执行

将草稿写入表格与流程图，确认参数及连线后运行任务。

版本说明：Windows 使用 v1.6.3，macOS 与 Linux 使用 v1.6.2。下载菜单已分别链接对应的 GitHub 程序包。

Built around you · 产品理念

流程在本地。
掌控在你手中。

从一个点击，到一套完整任务，AnClicker 把执行、扩展与控制交还给使用者。

01 / Local execution

本地执行

指令、配置、截图与日志保存在本机，便于备份和迁移。准备好依赖后，可运行不依赖网络的本地流程；网页与在线模型等能力按需联网。

02 / Open architecture

开放扩展

按需组合本地模型、OCR、视觉识别及外部接口。通过独立指令的参数编辑器与执行器扩展能力，让工具适应你的任务。

03 / Your control

由你掌控

模型辅助生成草稿，使用者检查参数并决定执行。运行、暂停、恢复与结束集中在控制面板，步骤可修改，流程可复用。

Behind the name · 名称释义

AnClicker按-点击者

An- 取自 Analog（模拟），谐音「按」，代表模拟人工触发；Clicker 意为「点击者」。这是一个自定义造词，承载着把日常操作变为自动化流程的想法。
