# v1.3.0 流程图右键切线

在空白位置按住右键划过连线：橙色高亮表示将被切断，松开后一次删除划过的所有连线。蓝色刀光和末端星芒在释放后 320 毫秒内消退。一刀对应一次撤销，沿用最多 20 步的连线撤销/重做。

- 只删除连线，不删除指令框体；表格中的命令保留，连接关系同步到其他视图。
- 实线、曲线和跳转虚线均支持；虚线空隙也属于同一条可切连线。
- 单击或微小抖动保留右键菜单；节点右键保留配置、复制和前后连线操作。
- 中键拖动平移，滚轮缩放。切割期间阻止滚轮改变命中坐标。
- Esc、失焦、隐藏窗口、调整窗口尺寸或加载项目会取消未提交的切割。
- 运行过程中不允许切线。未划过连线不会产生撤销记录。
- 不切框体遮挡下的不可见线段；预览高亮不覆盖节点文字。
- 特效仅在视口绘制，轨迹最多保留 160 点；动画结束停止定时器，不向项目加入特效节点或保存临时图形。

## 参考与实现边界

研究项目：<https://github.com/graphif/project-graph>，参考提交 `1fb1b5cc77d5d5a3820cbae4f5d5777339af63a0`。

阅读了 `ControllerCutting.tsx`、`LineCuttingEffect.tsx` 和 `EdgeCutEffect.tsx`，借鉴空白起刀、命中预览、释放提交和短时反馈的交互思路。上游 app/LICENSE 为 GPLv3；本次未复制或移植其源代码、音效或其他资产，而是为现有 PySide6 视图单独实现像素空间轨迹碰撞和绘制，并复用 An Clicker 现有批量删除、同步及撤销接口。

本次并非整体迁移 Project Graph 引擎。节点切除、音效和其其他布局功能不在本次实现中。
