# 离线模型目录

程序自动从程序文件夹中的 `ocr_models` 读取，不需要在指令内选择目录。

```
AnClicker.exe
ocr_models/
  rapidocr/   # 三个 ONNX 模型：检测、方向分类、文字识别
  wechat/     # 微信模型 Model/ 与其配套 exe、DLL
```

微信原生引擎依赖同级 `Model`，因此将其配套运行文件一并放在 `wechat` 内，不破坏其内部结构。
只使用一种离线引擎时，可以只分发对应的子文件夹。删除全部模型后，其他非 OCR 功能仍可用，离线识别会明确提示缺少模型，不会自动下载。
模型文件夹可独立备份、压缩和恢复；不要只删其中单个模型。运行库（例如 ONNX Runtime）仍属于程序依赖，不包含在模型文件夹内。

构建时默认将 RapidOCR 模型复制到统一目录，微信组件仍需要本地构建开关。旧版已发布包和旧测试目录不自动修改，本次使用新构建目录。
