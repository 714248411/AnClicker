# 多线程分组与嵌套

新建“多线程启动”默认入口编号为 0，使用流程图中从该线程连出去的步骤。后续步骤自动加锁为一组，到下一个多线程启动时划分新组；嵌套线程及其步骤包含在父组内。开始节点可以直接连接多个多线程启动，它们并列运行。

流程图中的多线程节点使用蓝色边框与普通指令区分。锁定后的拖拽与“折叠加锁”一致：拖动任一组内节点，整组按相同偏移量平移；保留组内相对位置，不改变其他指令的位置、表格顺序或连线。解锁后恢复原来的展开布局，并保留累计位移。主流程节点和多个线程共用的后续节点不加入自动锁定组，避免把独立线程拖动到一起。

表格中的多线程行默认收起，点击命令列的 ▶ / ▼ 可逐级展开或收缩。展开父组时会保留子组原来的折叠状态。加锁时，拖拽任一组内步骤会移动整个外层锁定组。

表格与流程图的多线程右键菜单都新增：

- **打开嵌套多线程**：将当前线程放入上方线程中；连续对下方线程打开嵌套，可形成多级结构。第一条线程没有上方线程，不能嵌套。
- **取消嵌套多线程**：将当前线程及其子线程整体提升一级，与原来的父线程并列运行；其他兄弟线程保持原归属。

例如 A、B、C 默认并列。依次对 B、C 打开嵌套后，结构为 A → B → C。对 C 取消嵌套后，B 与 C 同属 A，并列运行。

嵌套线程跟随父线程及主任务的暂停、恢复和停止。父线程执行完自己的步骤后会等待嵌套线程结束；主任务也会等待使用连线分组的线程完成。循环运行的线程需通过多线程关闭或停止任务结束。

分组、折叠与层级随项目保存，线程组复制时保留内部连线。已有非零入口编号继续使用原来的独立分支入口；也可以将入口改为 0 后按后续连线组织线程。折叠仅影响显示，不会跳过运行步骤。
