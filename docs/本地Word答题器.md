# 本地 Word 答题器

“后台功能”中的“本地Word答题器”使用本地 .docx 题库，无需后台窗口绑定或在线答题服务。

题库支持两种格式：

- Word 表格：第一列题目，第二列答案；可有“题目 / 答案”表头。
- 段落：以“题目：”开始题目，以“答案：”开始答案，下一道题再以“题目：”开始。题目和答案均可跨段。

设置题库路径，选择输入题目、最近 OCR 文字或变量作为题目来源。匹配方式包括精准、包含和模糊；模糊模式可设置相似度。包含模式要求完整题库题目出现在输入内容中。同等匹配存在不同答案时会报错，避免随意选取。

答案写入指定变量（默认“答案”），匹配题目与分数写入“答案_详情”。下一条文本输入指令可填写 {{答案}}。未匹配时可以报错或返回空值，并清空上一次答案。

旧 .doc 文件请先另存为 .docx。旧工作簿保留原指令类型标识，但在线答题参数需要改配为本地题库；不会继续发送旧在线请求。
