# 网页抓取工具

指令栏新增“网页抓取工具 → Crawl4AI 网页抓取”。输入网址，可选内容 CSS 选择器和等待元素，选择 Markdown、正文、链接或完整结果，保存到指定变量。指令支持原生编辑、测试、重复、异常策略和停止。

Agent 的直接工具模式可调用 crawl_page；默认草稿模式则生成可编辑的抓取指令。抓取浏览器与现有点击/输入浏览器分离，不共享登录态。当前支持单页抓取，不包含全站递归爬取。

安装：使用项目 Python 运行 tools/setup_crawl4ai_runtime.py。Crawl4AI 0.9.5 和 Chromium 安装在 .local/runtimes/crawl4ai，避免修改主程序依赖。可用 ANCLICKER_CRAWL4AI_PYTHON 指定专用解释器。

已实测：动态正文、CSS 范围选择、标题与链接、变量替换、Agent 工具调用、HTTP 404 和中途取消。停止时终止该次抓取及其浏览器子进程。页面失败不会写入结果变量。

依据：[官方安装文档](https://docs.crawl4ai.com/core/installation/)与[快速开始](https://docs.crawl4ai.com/core/quickstart/)。

## 快捷使用与结果预览

- 点击“粘贴网址”，自动补齐 https；或点击“选择已打开网页”，从 AnClicker 的普通浏览器和 Agent 浏览器中选取网址。不会启动新的浏览器，忙碌的浏览器会跳过。
- “快速方案”提供整页内容、文章区域和整理网页链接；CSS 范围、等待元素、超时和字符上限收纳在高级设置中。有自定义高级参数的旧指令会自动展开这些设置。
- “抓取预览”在后台执行，不更改变量。结果窗口可切换 Markdown、正文、链接 CSV 和完整 JSON，支持复制或保存当前内容，并显示截断提示。
- “查看上次结果”可再次打开最近一次成功预览。修改设置后需重新抓取，旧结果不会自动刷新。
- “停止抓取”或关闭编辑器会取消预览并释放后台进程；原有“测试并保存变量”仍走 AnClicker 的指令测试流程。

## 常用提取指令

“网页抓取工具”新增五个独立入口，填写网址即可使用，均支持 CSS 范围、动态元素等待、预览和保存到变量：

| 指令 | 输出 | 默认变量 |
| --- | --- | --- |
| 网页正文提取 | 清理后的正文字符串 | 网页正文 |
| 网页链接提取 | 网址和文字列表 | 网页链接 |
| 网页图片提取 | 去重的图片绝对地址及 alt 说明，不下载图片文件 | 网页图片 |
| 网页表格提取 | HTML 表格标题、表头和行数据，展开 rowspan/colspan | 网页表格 |
| 网页标题提取 | 页面标题及 H1–H6 层级标题 | 网页标题 |

通用 Crawl4AI 指令也可选择新增格式。图片、标题各最多 100 条；表格最多 20 个，每表最多 100 行、50 列；内容过长会截断并提示。表格提取适用于 HTML table，CSS 网格或图片表格不会被当作表格识别。图片、表格和标题预览可导出 JSON。
