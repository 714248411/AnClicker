# 定时运行项目

点击指令栏内左下角的闹钟打开设置。按钮跟随指令栏停靠、拖动及收起。

选择已有的 .xlsx 项目文件，填写说明、首次执行时间及重复方式，然后点击“创建”。支持每天、工作日（周一至周五）、每周、自定义分钟间隔，以及仅一次。时间使用电脑的本地时间。

“高级”内可查看任务列表和执行状态，并启用、停用或删除任务。程序需保持运行；关闭期间错过的启用任务，下次打开补执行一次，不重复补跑多个周期。

到期后，主任务在安全暂停点让出执行权。按住按键或鼠标拖拽期间会等到松开再执行定时任务。定时项目在独立数据库和变量上下文中执行，不替换主界面项目。完成或失败后恢复主任务；原来手动暂停的任务仍保持暂停。多个到期任务依次执行。

录制或指令测试期间延后执行。定时运行期间不能开始新录制、主任务或应用更新。“结束任务”会停止主任务及定时任务，并取消已排队的本次执行；以后周期仍按启用状态运行。
