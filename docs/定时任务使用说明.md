# 定时运行项目

点击指令栏内左下角的闹钟打开设置。按钮跟随指令栏停靠、拖动及收起。

选择已有的 .xlsx 项目文件，填写说明、首次执行时间及重复方式，然后点击“创建”。支持每天、工作日（周一至周五）、每周、自定义分钟间隔，以及仅一次。时间使用电脑的本地时间。

“高级”内可查看任务列表和执行状态，并启用、停用或删除任务。程序需保持运行；关闭期间错过的启用任务，下次打开补执行一次，不重复补跑多个周期。

每个定时任务可单独选择“主任务”运行方式，并随任务保存：

- **暂停主任务(结束后恢复)**：到期后，主任务在安全暂停点让出执行权，主任务录制回放中的按键或鼠标拖拽会等到松开。定时任务完成、失败或取消后恢复主任务；原来手动暂停的任务仍保持暂停。已有任务默认使用此模式。
- **定时任务不影响主任务运行**：定时任务启动、完成、失败或取消都不暂停、恢复或停止主任务；主任务原来运行就继续运行，原来手动暂停就保持暂停。定时任务运行期间也可启动主任务。定时任务使用独立数据库、变量上下文和浏览器会话，不替换主界面项目。操作同一前台键鼠、目标窗口或外部文件仍可能相互影响，应安排不同目标或使用暂停模式。

多个到期的定时任务仍按队列依次执行，每个任务按自己的模式与主任务配合。

录制或指令测试期间延后执行。定时运行期间不能开始新录制或应用更新；暂停模式下不能启动主任务。“结束任务”会停止主任务及定时任务，并取消已排队的本次执行；以后周期仍按启用状态运行。
