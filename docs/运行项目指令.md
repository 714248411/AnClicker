# 运行项目（一行指令）

在指令栏「流程」分类中新增「运行项目」。表格中只占一行，流程图中只生成一个普通节点，不会把目标项目展开、合并或替换当前项目。

## 使用方式

1. 将「运行项目」添加到表格或流程图，打开参数窗口。
2. 把一个 `.xlsx` 项目拖入路径输入栏，或点击「浏览项目」。路径可以手动修改。
3. 保存指令，在主界面启动；也支持表格的单行运行。
4. 要实现 A → B → C，在 A 的末尾添加运行 B，在 B 的末尾添加运行 C。

目标项目执行一次后返回调用者，继续后续指令。通用「重复次数」控制目标项目执行次数。目标文件里的主界面循环设置不覆盖当前任务的循环设置。可放在流程图分支中，执行顺序沿用现有连线规则。

## 路径、变量与安全

- 支持中文和空格路径；支持现有变量替换语法。
- 相对项目路径以调用项目所在目录为基准；未保存的主项目应使用完整路径。
- 目标项目旁的相对图像路径优先从目标目录查找，之后使用已有资源目录查找逻辑。
- 子项目使用独立临时数据库读取、校验，兼容现有旧版工作簿迁移入口，不修改原文件或当前表格。
- 调用链共享运行时变量；目标项目声明的缺失变量作为默认值补入，同名变量保留当前值。持久化仍由当前主项目已有全局变量规则负责。
- 项目文件可能包含 Python、命令行等自动化操作，请只运行可信文件。
- 阻止直接及间接循环调用，限制最多 32 层嵌套；重复执行同一项目不视为循环引用。

## 暂停与停止

所有子项目在同一个工作线程中执行，沿用暂停、停止按钮和全局 Esc。停止会中断整个调用链，不再运行父项目剩余指令；隐藏窗口恢复行为沿用主界面已有逻辑。

时间等待已改为可协作中断，不必等完整等待时长结束。外部程序、第三方库等阻塞调用仍受现有停止超时机制约束。参数窗口不直接同步执行整个项目，避免占用界面线程；请保存后使用主界面运行或单行运行。
