# 网页后台操作

指令栏新增“网页后台操作”：后台网页点击、后台网页点击（可多点）、后台网页按键。

每条指令设置顶部均有“打开网页”“刷新窗口”。拖入或重新打开设置时异步刷新一次窗口列表；后台请求不会阻塞参数编辑。选择窗口后进行网页取点，单点只能选择一个点，多点支持依次取点及设置点间隔。执行通过 CDP Input 发送真实输入，不激活或恢复桌面窗口，不移动系统鼠标。

“打开网页”使用 AnClicker 自带浏览器创建独立持久会话。网址、窗口大小、稳定会话标识保存在 Data/rpa-browser/cdp-pages.json，Cookie、LocalStorage 等持久数据保存在同目录的 Chromium 分区。下次进入 CDP 设置或执行后台指令时恢复网页，等待加载后操作；原指令通过稳定会话标识重新关联窗口。不同窗口的数据隔离。浏览器“清空登录数据”也会清理这些持久分区。

刷新窗口仅刷新列表，不重新加载网页。取点与“打开网页”为交互操作，会显示目标窗口；后台执行不抢焦点。原网页自动化创建的临时窗口仍可操作，但不会被转换成持久会话。需要跨次恢复时请用上述“打开网页”创建。

验证：tools/check_background_web.py（内置浏览器实际点击、按键、前台窗口不变、最小化、数据隔离、重启恢复、无效窗口与越界坐标）；tools/check_background_web_ui.py（单次异步刷新、打开按钮、窗口重新关联、关闭安全）；原网页多窗口回归 tools/check_web_windows_and_stack.py。

刷新窗口会合并所有已连接的内置浏览器及外部浏览器页面，包括网页自行打开的弹窗；已关闭的页面会移除。某个浏览器连接失效时仍保留其他可用窗口。同时读取本机 Chrome / Edge 等浏览器进程声明的调试端口，连接已经打开的外部浏览器，不要求由 AnClicker 启动。支持固定端口和自动分配端口，关闭的标签页会在刷新后移除。外部会话数据由原浏览器管理；“打开网页”会导航所选外部标签页。未开启远程调试的普通浏览器无法直接连接，需另行以启用 CDP 的方式启动；程序不会擅自关闭或重启现有浏览器。

外部浏览器验证：tools/check_remote_cdp.cjs（独立 Chrome、真实 CDP 点击与按键、多标签隔离、无效目标和关闭刷新）；tools/check_cdp_discovery.py（端口发现与过滤）。

后台网页按键的自定义内容支持连续字符，例如 aaaaa 按顺序发送五次 a。按键间隔默认 0.1 秒，可修改；“按几次”重复整段字符。F5、Enter 等命名按键与 Ctrl+Shift+A 等组合键作为一次按键，不拆分。间隔等待支持停止。

连续字符中的加号和空格按字符发送；功能键名称忽略大小写，Ctrl++ 表示 Ctrl 与加号组合。“按几次”范围为 1–20，更多轮可设置指令重复次数；导入的超范围值会报错，不再静默截断。后台指令执行超时会为设置的按键/点击间隔预留时间，停止仍保持响应。
