# AnClicker v1.5.7

- 修复参数测试与主任务、录制同时运行造成的冲突；测试期间按停止快捷键或关闭主窗口会先安全取消测试。
- 键鼠、图像等待和窗口焦点等待等参数测试改为后台执行，提供取消入口，避免长时间占用界面线程。
- 加强主任务、定时任务及参数测试的异常清理；后台组件释放失败、变量读取失败会显示错误并结束任务，避免异常直接越过工作线程。
- 优化大流程的注释状态计算与表格重复刷新，减少大量指令下的界面停顿。
- 后台组件支持首次使用自动下载、校验和配置，后续复用本地组件；保留手动配置与授权入口，下载可取消。

支持 Windows、Linux 与 macOS。大漠后台组件仅适用于 Windows；不同目标程序对后台绑定的支持仍以实际兼容性为准。
