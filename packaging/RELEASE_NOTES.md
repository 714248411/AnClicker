# AnClicker v1.6.1

- 优化主界面与导航布局：表格图、流程图、多功能分组排列；录制、网页录制独立成组，统一圆角、间距和深浅主题对齐。
- 默认锁定可编辑视图；进入表格图或流程图时自动展开指令栏，主界面收起指令栏。
- 工具栏支持长按拖拽排序及相邻按钮让位；可从菜单添加常用功能，超出窗口宽度的项目自动收纳。
- 压缩键鼠录制和网页录制的控制区，统一排列方式，为录制内容保留更多空间。
- 新增动作延时高级设置：截图识别到点击的间隔、点击后等待、双击/连击间隔、鼠标按下持续时间和统一指令间隔均可调，支持 0.001 秒精度及一键归零；图像点击和其他指令均提供入口，普通设置不再承载这些选项。
- 默认识别后立即点击，移除额外的鼠标库点击后暂停；设置延迟后会再次确认目标，等待期间支持停止并释放按键。
- 复制多条指令后，按住 Ctrl + 左键拖动其中任意节点，可平移同一次复制的整组指令；松开保存，Esc 取消。
- 流程图操作说明改为可轮播的小提示，补充整组平移、右键拖拽删除连线等实际操作；右键可收起提示。
- 整组节点坐标改为一次事务保存，避免多节点逐条写入造成的停顿；取消拖动时批量恢复，减少重复连线计算。

复制组的关联在当前应用会话中保留，已保存的节点位置可重新载入。性能数值以实际机器和流程规模为准。
