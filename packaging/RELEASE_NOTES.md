# AnClicker v1.5.4

- 新增定时运行项目：安全暂停主任务、依次运行到期项目，完成后继续；支持每天、工作日、每周、自定义间隔和单次任务。
- 修复表格添加指令时按 Tab 触发自定义快捷键的闪退问题。
- 修复指令栏收起再展开后尺寸改变，以及菜单、下拉列表和设置窗口的白边。
- 优化指令参数设置留白，字体加大一号，高级设置向下展开；取点、OCR、图像和网页参数布局统一检查。
- 优化定时任务深浅主题、日期选择、说明框高度调节及高级任务列表。

完整解压后运行。升级前备份自己的 data；应用包不包含开发者项目、录制数据或上传凭据。定时任务需保持程序打开，不能唤醒已关闭的程序。录制期间延后运行，手动暂停状态会保留。
