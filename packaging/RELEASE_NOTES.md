# AnClicker v1.5.3

- 新增界面方案：保存、应用、删除、更名及恢复默认布局，保留快捷指令顺序。
- 新增界面字号菜单，可统一增减字号和图标大小、恢复默认并记住选择。
- 拖拽停靠提示跟随目标栏，在目标栏内部显示上下左右位置，可并排、堆叠或合为标签。
- 控制与操作停靠在表格上方、下方时统一两列布局；空间不足时缩小字体和按钮。
- 修复指令栏左右切换高度变化，以及保存方案后打开指令参数干扰控制面板布局的问题。
- 优化指令参数深浅主题，去掉白边并缩小一号字体；图像点击的当前文件夹和目录改为同一行。
- 搜索指令右键菜单改为中文；控制与操作按钮按状态显示收起或展开；捐赠移到帮助后面。
- 中文编程提示及快捷键设置移入工具菜单；可编辑视图控制拖拽内嵌，关闭后仍可通过右键内嵌。
- 检测到新版本时由用户选择更新或稍后更新；稍后提示收回更新入口并高亮，不自动下载安装。

Windows 请完整解压 ZIP，双击根目录 An Clicker.exe，保留目录结构和 data 用户数据目录。
Linux、Mac 请阅读包内平台使用说明；Mac 包分别包含 Intel 和 Apple Silicon 原生应用。
