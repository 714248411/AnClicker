# AnClicker v1.5.2

- 新增上、中、下、左、右区域布局：指令表格和流程图固定在中栏，其他工作面板可拖到周围栏目。
- 同一区域支持横向并排、纵向堆叠和标签组合，布局自动保存。
- 指令参数设置右击可融入主窗体；面板双击标题可窗口化，再双击重新嵌入，保存和取消沿用原参数校验。
- 去掉指令栏、控制与操作、日志、参数设置的额外顶部拖拽条和关闭按钮；直接拖动搜索栏或内容标题，双击窗口化/嵌入，其他操作放入右击菜单。
- 指令栏、控制与操作、参数设置在窄区域内自动换行并按比例缩小字体、控件和间距，必要时保留滚动。
- 控制与操作放到底部时，左边显示设置，右边竖排开始、暂停/恢复、结束按钮。
- 修复布局恢复和小窗口切换时的面板归属与显示问题。

完整解压 AnClicker-v1.5.2-win.zip，双击根目录 An Clicker.exe。保留整个目录结构；用户数据在 data 中。

拖动“运行日志”文字、“控制与操作”标题或指令搜索栏也可移动对应面板；输入与普通控件点击仍可正常使用。

“视图”新增“恢复默认视图”，还原面板位置和大小，保留快捷指令顺序；未保存参数以独立窗口保留。

进入多功能界面时自动隐藏指令栏，离开后恢复原来的展开/收起状态。

- 指令参数窗口化保留原弹窗尺寸并居中，右上角可关闭取消；嵌入后隐藏额外标题栏。
- 键鼠多坐标点击增加连续取点画布，半透明红色圆圈连续编号、拖动调整和撤回；取消保留原值，不再限制为 1000 点。
- 指令设置默认以独立窗口居中打开，右击上方栏可融入主窗体，右上角关闭取消未保存修改。
