# An Clicker v1.3.3 标准版

## v1.3.3 更新

- 新增 11 个本地 OCR 拖拽模块；RapidOCR 模型随完整包离线提供，微信 OCR 提供可选本机组件适配（真实微信组件尚未验收，不随包分发）。

- 新增离线真实模型、区域偏移、多个结果选择、取消和超时测试；打包门禁增加真实 OCR 子进程识别检查。
- 使用说明与限制见 [LOCAL_OCR.md](https://github.com/714248411/AnClicker/blob/main/LOCAL_OCR.md)。升级前备份 data，完整解压。Gitee 本轮不发布。

## 跳转流程

- **报错跳转**：将源指令右侧异常接口连接到此模块才启用。支持跳到连线节点、当前项目指定行、其他项目指定行，或继续执行。行号从 1 开始，目标行本身会执行。
- 当前项目跳转从目标继续，丢弃原路径待执行分支；外部项目完成后返回调用位置继续，可随时中止。缺少目标、无效行号或项目执行失败时停止并记录错误。
- **变量比较**：比较变量与固定值或另一变量，支持自动、数字、文本，以及等于、不等于、大小、包含等比较；是、否分支分别配置连线节点或当前/外部项目行。
- 跳转和异常连接使用外围虚线，虚线间距按视口尺寸设置，不随画布缩放变化。复杂图可能仍有交叉。

## 流程图交互

- 箭头吸附在目标矩形/菱形外侧，沿实际连线方向指向终点，避免框体遮挡。
- 空白处按住右键划过连线，橙色高亮预览，松开切断；支持实线、曲线与跳转虚线。一刀计一步撤销，沿用最多 20 步撤销/重做。指令框体和表格命令保留。
- 蓝色刀光、末端星芒和短时渐隐特效；Esc、失焦、隐藏窗口、调整窗口尺寸或加载项目取消未提交切割。运行/录制中不允许改线。
- 保留右键菜单、中键平移、滚轮缩放、表格与多功能联动，以及录制倍速写入。
- 开源交互设计来源及致谢见仓库 README 底部，Qt 实现独立编写。

升级前备份 `data`，完整解压新包后迁移自己的数据。本版为 PySide6 标准版；Win10 1607 旧系统用户请使用独立的 v1.2.6-legacy。源码不包含七牛部分。
