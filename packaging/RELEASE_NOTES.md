# v1.2.7 标准版

基于 v1.2.6 标准版（PySide6）更新，不修改 v1.2.6 PyQt5 旧系统版。

- 录制页新增“按倍速写入表格与流程图”，默认 1.25 倍，自定义范围 0.10–10.00 倍；原速写入保留。
- 倍速缩放录制时间轴，不改变操作顺序、坐标、按键和按下/松开配对；表格、流程图、多功能同步。实际运行时间仍受系统输入性能影响。
- 默认停止录制后先预览，自选原速或倍速；仍可勾选“停止后自动写入（原速）”。需要倍速效果时保留操作时间间隔。
- 流程图空白处按住鼠标中键拖动画布，内容跟随鼠标平移；向左拖动即可查看右侧内容。高倍缩放下保持屏幕像素位移一致，支持细小连续移动。
- 保留滚轮缩放、左键框选及右键菜单；松开中键或失焦结束平移，防止拖拽状态残留。
- 保留标准版分栏美化，不包含七牛或自动更新。

提供 Windows x64、macOS Intel/ARM64、Linux x64 完整包。升级前备份 data，完整解压后使用；不是 Win10 1607 旧系统版。

## v1.2.6 基线功能

基线：GitHub v1.2.2，提交 27db7aa24b7c52eb57ca023a2b1c8446f24f9bbd。
本次在旧版上加入连线操作与控制面板运行开关，不以先前的 v1.2.4/v1.2.5 为基线。

- 单根/框选连线右键删除；方块右键保留原有配置、备注、复制、删除和前后连线操作。
- 多选时前后连线菜单仍可见，仅作用于右键点击的方块。
- 撤销连线、回退连线（重做）两行，最多 20 步；批量删除计一步。
- 保留分支类型与指令顺序；导入项目、节点结构变化后清空历史；运行/录制中阻止改线。
- 控制与操作新增默认勾选的“运行未连接模块”，位于“运行时隐藏窗口”上方。取消后全部运行跳过孤立节点；选项保存，运行时禁止修改，小化模式可见。
- 不合入自动更新或七牛功能。

通过 Windows、Linux、macOS Intel/ARM64 测试及首次/再次启动验证后发布完整包。升级前请备份 data 并完整解压。
