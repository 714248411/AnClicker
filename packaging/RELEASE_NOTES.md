# An Clicker v1.1.0

本次发布为整合全部功能的完整新版，不是补丁。提供 Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon ARM64 四个 ZIP 软件包，无需安装 Python。

## 新增与改进

- 导航后新增“录制”视图（Ctrl+6），支持键盘按下/松开、组合键、鼠标移动、左/右/中键点击、拖拽与垂直滚轮。
- 支持倒计时开始、隐藏控制窗口、F8 停止、保留操作间隔、自动连线和停止后自动写入。
- 录制内容事务性追加到指令列表，联动表格、流程图、多功能及保存文件，不覆盖已有任务。
- 停止时补齐松开事件，回放停止或异常时释放本次按住的键鼠，防止卡键。
- 修复跨平台按键映射，保留采样间隔内的鼠标末尾位置；Windows 控制界面输入排除兼容高 DPI。
- 条件判断菱形顶部为“否”输出、右侧为“是”输出、左侧为输入，角部命中区域不重叠，分支角色持久化。
- 优化大量指令节点的加载与连线路由，减少界面卡顿及不必要的交叉。
- 保留主界面、表格、流程图、多功能、导航功能，以及主题、保存、循环安全与连线优先执行机制。
- 窗口、关于页、EXE 属性、macOS 应用版本统一为 v1.1.0。

## 验证与限制

- 发布前执行自动化回归和实际打包程序首次、再次启动检查；用户已确认 Windows 录制回放验收正常。
- 鼠标移动通常每 50ms 采样，点击、按键或停止前补记末尾位置；最多 2000 个事件，达到上限自动停止。录制不是逐像素、逐帧无损捕获。
- 水平滚轮和不支持的特殊按键会停止录制并保留预览。输入法、系统安全窗口、游戏等特殊场景不保证一致回放。
- macOS 录制需授予辅助功能/输入监控权限，自动化截图需屏幕录制权限；Linux 全局录制需要 X11，Wayland 暂不支持。
- 各平台由 GitHub Actions 原生构建并检查启动；Windows 手动验收不等同于 macOS/Linux 实机录制验收。
- 仅主动开始录制后监听，停止/退出后解除监听，请勿录制密码等敏感内容。

## 使用与升级

完整解压后，Windows 运行 `AnClicker/AnClicker.exe`，Linux 运行 `AnClicker/AnClicker`，macOS 打开对应架构的 `AnClicker.app`。依赖文件须与程序一同保留。

升级前备份旧版 `data`。新版可放在独立目录；Windows 继续使用旧任务时，将旧版 `data` 复制到新版程序目录。首次打开会自动初始化可写数据目录与默认配置。
