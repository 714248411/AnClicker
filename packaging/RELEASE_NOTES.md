# AnClicker v1.5.0

- 修复主窗口最大化、小化和还原切换时尺寸逐次缩小；优化可拖动面板、底部间距和明暗主题。
- 重写内置浏览器导航：地址栏独立于网页，回车跳转；右上角按钮展开或隐藏工具栏，支持前进、后退、刷新、停止和缩放，失败后可修改地址重试。
- 网页元素拾取跟随流程上方最近网址；优化网页取点，多点编号和拖动调整，支持默认关闭的随机偏移。键鼠新增多坐标点击。
- 完善中文编程提示及下一步快捷操作，旧操作收起并保留参数；可在设置中启用、停用提示，修改快捷键。
- 键鼠和网页录制支持预览右键删除、接续录制；键鼠可选录制轨迹，网页保留等待时间。小书本提供完整中文说明。
- 优化设置、表格、流程图、多功能和右键菜单，修复黑色主题快捷键设置的文字显示。
- 删除指令使用中文确认和取消按钮，回车默认确认；保留最近关闭的界面。
