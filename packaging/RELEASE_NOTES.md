# AnClicker v1.6.2

- 在“网页录制”旁新增独立“对话 Agent”页面，支持对话、可收起的草稿和模型设置，适配深浅主题及窄窗口。
- 对话可查询指令栏与参数、生成及修改指令草稿；草稿可用原编辑器调整，再写入表格与流程图，支持标准 JSON 导出和导入网页录制草稿。
- 增加 Agent 独立浏览器的打开、查看、输入、点击和滚动操作；使用当前页面元素校验，避免复用失效的位置。
- 支持本地小模型及 Ollama / OpenAI 兼容 HTTP 模型服务，统一工具调用与错误返回格式，便于后续更换模型。
- Windows 增加 CPU/GPU 自动调度、显卡不可用时回退 CPU、跨进程请求排队和空闲释放；默认空闲 5 分钟释放模型，下次请求自动唤醒。
- 修复对话线程信号与 Qt 原生事件方法的命名冲突；加强参数校验、停止处理和草稿重复写入保护。

Windows 本机模型使用单独的可选运行包，Qwen2.5-0.5B Q4_0 权重约 429 MB；运行内存与文件体积不同。Linux/macOS 的对话页可配置 Ollama 或兼容模型服务，本次不附带其原生推理运行器。小模型适合清楚的单步任务，复杂自由规划仍需拆分任务。指令草稿不会自动执行；涉及循环和判断时请检查流程连线。
