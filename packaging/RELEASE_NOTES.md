# AnClicker v1.5.8

- 后台绑定新增截图 / 识图 / 取色开关，仅执行键鼠操作时可关闭；默认取消额外绑定等待，同一有效窗口可复用绑定，保留手动延迟设置。
- 优化后台绑定策略，自动模式优先尝试 DX1、DX2，并复用当前任务中已成功的配置；目标失效或配置变化时重新绑定，避免操作误落到前台。
- 修复流程图循环与后续分支的执行顺序：循环体全部完成后才执行后续流程，支持嵌套循环；条件判断优先于普通流程。
- 条件循环与变量比较可根据相邻指令建议变量，支持手动更改，并保留已填写的条件。
- 表格按流程图将循环行放在循环体上方，循环内容缩进显示，可右击展开或收起；嵌套折叠、运行定位与项目保存保持一致。
- 修复条件分支未选中指令被当作未连接指令补跑的问题，保留条件循环逐轮判断的执行方式。

支持 Windows、Linux 与 macOS。大漠后台组件仅适用于 Windows；首次绑定仍需初始化第三方组件，不同目标程序的后台兼容性以实测为准。
