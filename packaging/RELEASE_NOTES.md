# An Clicker v1.1.9

## 本版重点

- 修复运行缓存清理的线程风险：垃圾回收和图像缓存清理统一排队到界面线程，避免在工作线程中销毁 Qt 界面对象。

- 新增「运行项目」：表格只占一行、流程图对应一个节点，拖入或浏览选择 `.xlsx` 项目，支持 A→B→C 串联。目标执行一次后返回并继续；不展开或替换当前项目，不修改目标文件。
- 所有子项目共用同一个工作线程及停止 / Esc 机制，阻止直接或间接循环调用，最多 32 层嵌套。时间等待支持及时协作中断。
- 修复旧版「等待到指定图像出现/消失」选项无法迁移的问题；导入、编辑、执行兼容旧名称，保留旧版等待消失不限时语义。明确显示「0 不限」，支持中断，缺失图像文件不再误判为消失成功。
- 参数窗口中的不限时等待需保存后使用表格单行运行测试，避免阻塞界面线程。
- 相对项目路径按调用项目所在目录解析；未保存的主项目请使用完整路径。共享运行变量，目标项目中缺失变量以默认值补入，同名变量保留当前值。仅运行可信项目；外部程序及第三方阻塞调用仍受已有停止超时机制约束。
- 本版为完整包，不是补丁。发布流水线对 Windows、Linux、macOS Intel、macOS ARM64 分别测试、构建并检查首次/再次启动。

## 继承 v1.1.8 功能

- 指令悬停高亮：流程节点增加外侧柔和光晕、浅色底纹和边框，文字绘制于最上层；指令栏及表格增强悬停反馈，跟随深浅主题。
- 修复节点获取坐标时模态编辑窗口提前退出/释放的风险；点选、Esc 取消和获取失败后恢复原窗口透明度。
- 新增“颜色判断”：指定坐标、RGB/十六进制颜色、0–255 单通道容差、相等/不相等、可选结果变量。流程图以菱形显示，右侧“是”、顶部“否”，支持表格/工作簿/多功能投影联动。
- 保留连线优先、未执行命令按加入顺序补执行的规则。此新增功能不代表任意旧版颜色参数与跳转格式均已完成迁移。
- 模拟验证不等同于所有目标软件的实机验收。

## 完整包与继承功能

本次为完整新版，提供 Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon ARM64 四个平台压缩包，不是修复补丁。

## 新增与修复

- 合并重复“视图”菜单，工具栏显示/隐藏开关移入保留的视图菜单。

- 修复“小化”模式强制禁用隐藏运行的问题：可正常勾选，退出小化保留最新选择；隐藏后 Esc / 原停止快捷键可中断，结束后恢复小化控制台。包含以下 v1.1.6 全部功能。

- 隐藏运行时可通过原停止快捷键或临时全局 Esc 中断；停止、完成及启动失败后恢复主界面。Esc 不可用时保持窗口可见；闲置时不额外占用 Esc。

- 控制与操作新增最近项目下拉框，末两级目录及文件名缩略显示；点击编辑完整路径，回车打开，悬停可查看完整路径。修改路径不重命名文件夹。
- 拖入单个 .xlsx 项目到路径栏、主界面、表格、流程图或多功能区域即可打开。不同视图共用同一项目文件，不执行拖入的脚本。切换前确认保存，运行/录制中阻止切换。
- 鼠标拖拽明确按住后分步移动，停止/异常释放按键；轨迹下拉菜单默认直线，可选参考 HumanCursor（MIT）适配的随机贝塞尔曲线与加减速，终点精确。录制路径保持原样。
- 新增悬停后点击：默认悬停 1.5 秒、连续移动 1 秒、点击前等待 0.3 秒，均可修改；支持原地点击及左/右/中键动作。
- 坐标获取改为遮罩点选目标，避免误读按钮自身坐标。
- 主窗口增加浅灰细边框和边缘层次；Windows 接入 DWM 外阴影，最大化收起。
- 新旧数据迁移支持多个独立分支、两列 INI 设置表；各分支分别输出，生成原始备份、迁移报告和缺失图片清单。
- 压缩包内新增独立“旧版数据迁移工具”文件夹：Windows 双击启动迁移器.cmd；macOS/Linux 使用 bash 启动迁移器.sh。须与主程序目录一起完整解压。

## 验证与限制

自动化测试验证鼠标保持/停止释放、虚拟悬停菜单、路径/拖入和数据保存重读；原生构建检查首次/再次启动及 100%/200% 缩放。模拟测试不等于所有目标软件的实机验收。

旧版工作簿实际样本的 41 条指令及两个分支已验证转换，原文件不修改。原图片仍需提供；缺失图片无法凭 Excel 恢复。跨分支跳转、未知指令或部分历史配置不会静默强行转换，以迁移报告为准。旧快捷键等配置归档但不自动覆盖新版偏好。

Windows 外阴影依赖桌面合成器；macOS/Linux 的外阴影由窗口管理器决定。macOS 自动化需相关辅助功能/输入监控/屏幕录制权限；Linux 全局录制依赖 X11。特殊安全桌面、硬件 Fn 或高权限目标不保证支持。

升级前备份现有任务和 data。完整解压后启动对应平台的 AnClicker 程序；不要只复制 exe，也不要继续使用指向旧版本的快捷方式。
