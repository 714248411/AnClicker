# An Clicker v1.1.4

本次发布为整合全部功能的完整新版，不是补丁。提供 Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon ARM64 四个 ZIP 软件包，无需安装 Python。

## 新增与改进

- 修复识别精度、重复次数等数字输入框显示不全：清除内部文本框重复边框与留白，统一数字输入框高度及上下箭头区域；所有独立指令的通用重复次数同步适配。
- 发布前直接在实际打包程序中打开 35 种指令编辑器，检查深浅主题下数字文本区域高度，并确认图片点击加载新版资源选择、快捷截图和点击位置布局。首次/再次启动覆盖 100% 和 200% 缩放，本地另外检查 150%。
- 如果仍看到“图像路径 + 浏览图像”的旧通用表单，请确认运行的是本版本完整解压目录中的程序，而不是旧快捷方式；本版本图片点击上方应显示“快捷截图”和资源文件夹选择。

- 主题按钮左侧新增“小化”按钮，仅显示控制与操作；原运行日志移至中间，可拖动分隔条调整日志与按钮区域，窗口最小约 280×350，字号随尺寸缩放。
- 小化复用原控制按钮和日志，不清空任务或中断运行；暂时禁用运行隐藏窗口，退出后恢复窗口尺寸、布局及隐藏偏好。
- 图像点击恢复旧版资源文件夹/图片选择、快捷截图、灰度、精度滑块、区域开关、功能参数与图片预览布局，继承最新版深浅主题。
- 点击位置支持图片内十字线点选/拖动、中心复位、手动偏移和随机位置；修复误用屏幕坐标及随机位置越界一像素的问题。

- 深色外观改为近黑背景、炭灰面板、浅灰文字与蓝色强调，流程图配色同步；浅色默认值和主题记忆不变。
- 主题切换移到右上角最小化按钮左侧：深色显示太阳，浅色显示月亮，移除工具栏中的主题文字按钮。
- 新标题栏支持拖动、双击最大化/还原、边缘缩放、最小化和关闭，关闭仍经过原有保存确认流程。
- 新增全局变量、普通变量及自定义新增、编辑、删除。全局变量保存运行结果，普通变量在本次任务内共享，下次运行恢复初始值；旧变量自动迁移为全局变量。
- 导航 → 变量，或 Ctrl+Shift+V 打开管理；获取时间、剪切板、Excel、OCR 等 9 类指令恢复变量下拉选择与“设置变量”。
- Windows 录制保留原始虚拟键码、扫描码和扩展标志，支持左右修饰键、组合键、功能键、小键盘、媒体键、浏览器键及长按重复，区分主键盘和小键盘回车。
- 支持鼠标移动、点击、双击、侧键、拖拽、水平/双向滚轮，以及 Windows 精细滚轮增量。
- 支持倒计时开始、隐藏控制窗口、保留操作间隔、自动连线和停止后自动写入。Esc、停止按钮和可选 F8 均可结束录制，停止快捷键不写入结果；取消 F8 停止选项可录制 F8 本身。
- 录制内容事务性追加到指令列表，联动表格、流程图、多功能及保存文件，不覆盖已有任务。
- 停止时补齐松开事件，回放停止或异常时释放本次按住的键鼠，防止卡键。
- 焦点变化后仍保留已按下输入的松开事件，中断回放时释放原生特殊键和侧键。修复侧键指令重新编辑时的参数校验问题。
- 优化深浅主题、文字换行、按钮尺寸、小窗口滚动和高 DPI 显示，补齐下拉与步进箭头。
- 条件判断菱形顶部为“否”输出、右侧为“是”输出、左侧为输入，角部命中区域不重叠，分支角色持久化。
- 优化大量指令节点的加载与连线路由，减少界面卡顿及不必要的交叉。
- 保留主界面、表格、流程图、多功能、导航功能，以及主题、保存、循环安全与连线优先执行机制。
- 窗口、关于页、EXE 属性、macOS 应用版本统一为 v1.1.4，包含此前版本的变量、录制、主题、小化及图片点击修复。

## 验证与限制

- 发布前执行自动化回归和实际打包程序首次、再次启动检查；模拟输入验证不等同于所有设备的实机验收。
- 鼠标移动每 10ms 采样，按键、点击和滚轮不降采样；最多 20000 个事件，达到上限自动停止。不是逐像素、逐帧无损捕获，回放精度受系统负载影响。
- 原始系统键码需在对应系统回放。硬件 Fn、Ctrl+Alt+Del、安全桌面和被驱动截获的操作无法保证录制/回放；输入法候选结果取决于当前输入法状态。高权限目标程序可能拒绝模拟输入。
- macOS 录制需授予辅助功能/输入监控权限，自动化截图需屏幕录制权限；Linux 全局录制需要 X11，Wayland 暂不支持。
- 各平台由 GitHub Actions 原生构建并检查启动，不等同于 macOS/Linux 实机录制验收。
- 仅主动开始录制后监听，停止/退出后解除监听，请勿录制密码等敏感内容。

## 使用与升级

完整解压后，Windows 运行 `AnClicker/AnClicker.exe`，Linux 运行 `AnClicker/AnClicker`，macOS 打开对应架构的 `AnClicker.app`。依赖文件须与程序一同保留。

升级前备份旧版 `data`。新版可放在独立目录；Windows 继续使用旧任务时，将旧版 `data` 复制到新版程序目录。首次打开会自动初始化可写数据目录与默认配置。
