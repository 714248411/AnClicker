# An Clicker v1.2.4

- 新增“运行未连接模块”开关，默认开启，位于“运行时隐藏窗口”上方。
- 流程图可右键删除单根连线，支持最近 20 步连线操作撤销。
- 精简表格、日志与分栏重复边框。
- 合并通用 Windows 更新接口及数据目录隔离，修复更新检查期间的退出与项目打开问题。
- 本次源码不包含七牛发布脚本、SDK、配置或密钥，不向七牛及 Gitee 上传。
- 未配置更新源；源码运行和普通 ZIP 不自动更新。
- 提供 Windows x64、Linux x64、macOS Intel x64 和 Apple Silicon ARM64 完整压缩包。由 v1.2.4 标签源码构建，分别通过测试及首次、再次启动验证后发布。
- 安装 requirements.txt 后执行 python main.py；升级前备份现有 data 和任务文件。
