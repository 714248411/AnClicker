# AnClicker v1.6.0

- 后台常用设置向前台对齐：合并坐标与范围输入，精度滑条、按键选择与捕获、多行文本粘贴；偏色、搜索方向和专用参数放入高级设置，保留旧配置与变量。
- 颜色判断的“获取坐标和颜色”同时读取点选位置和颜色；“选择颜色”只修改颜色，均可手动编辑，取消或取色失败时保留原内容。
- 修复截图期间关闭参数窗口后延迟回调访问已释放控件的问题；截图选定后立即保存，避免确认按钮抢先处理。
- 优化已有后台指令的设置窗口：直接载入保存的参数，避免重复创建控件，减少打开耗时。


后台操作仍使用绑定窗口的内容区坐标；高级设置保留原始参数、变量引用和既有执行方式。颜色判断支持 #RRGGBB 与 R,G,B，坐标、颜色均可继续手动修改。
