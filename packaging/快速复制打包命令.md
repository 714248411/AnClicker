# 快速复制打包命令

在项目根目录 PowerShell 执行。完整验证和恢复规则见 [AI打包并发布说明.md](AI打包并发布说明.md)。版本来自 `info.py`，先更新 `packaging/RELEASE_NOTES.md`。

## 初始化

```powershell
uv sync --python 3.11 --group release
dotnet tool restore
$env:QINIU_BUCKET = "ytsoftware-velopack"
$env:QINIU_REGION = "z0"
$env:QINIU_KEY_PREFIX = "an-clicker/win-x64"
$env:QINIU_PUBLIC_BASE_URL = "https://<绑定该桶且证书有效的下载域名>"
```

发布时在受保护环境中注入 `QINIU_ACCESS_KEY=<维护者AK>` 和 `QINIU_SECRET_KEY=<维护者SK>`。构建不需要这两个变量；勿把真实密钥粘贴进文件或命令历史。

## 普通 ZIP 构建（无自更新）

```powershell
uv run python -m PyInstaller --clean -y packaging/main.spec
uv run python packaging/smoke_release.py
uv run python packaging/build_release.py
```

## Velopack 仅构建

```powershell
uv run --group release python packaging/发布Velopack.py build
```

## 发布已经验证的产物

```powershell
uv run --group release python packaging/发布Velopack.py publish --yes
```

## 构建并发布

```powershell
uv run --group release python packaging/发布Velopack.py build --publish --yes
```

产物目录：`dist/velopack/win-x64`。两种发布命令均重新执行发布门槛；AK/SK 只在发布进程读取。用户端使用构建固化的公开地址。真实域名尚未配置时，不使用当前测试域名替代或关闭 TLS 校验。
